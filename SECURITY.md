# Security policy

Supported: latest main. Demonstration / research repository.

## Reporting
Do not open public issues containing secrets or wallet addresses. Use GitHub private vulnerability reporting if available.

## In scope
Strategy code, risk gates, redaction, audit, mode guards, recommended CI patterns.

## Protections
- Secret refusal and redaction
- Paper-only mode
- Hash-chained audit
- Recommended gitleaks + personal-data tripwire

Rotate any leaked credential outside this repository.
