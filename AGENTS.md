# AGENTS.md — rules for AI coding agents

Adapted from the zeekiankok92 harness style.

## Scope
- Work only on the stated task. One task = one branch = one PR.
- Never push to main, merge own PR, or weaken security gates.

## Data and privacy
- Use only synthetic fixtures or clearly public open data.
- Never paste production personal data, wallet addresses, private keys, or real exchange credentials into prompts, code, or fixtures.
- Fixtures must be labelled SYNTHETIC and preferably generated by script.

## Secrets
- No API keys, tokens, mnemonics, or passwords in the tree.
- Read any optional read-only market keys from environment only.
- Treat gitleaks or redaction flags as real incidents.

## Engineering
- Prefer stdlib or carefully approved dependencies.
- Tests must not call the network; inject fetchers.
- Paper-only constraints are non-negotiable.

## Disclosure
- Commits that are AI-assisted should carry `AI-Assisted: yes` trailer.
- Update disclosure logs where appropriate.

## Definition of Done
CI-style gates green (lint, tests, secret scan, personal-data tripwire) + human review.
